# Localisation and accessibility

- Every string through the engine's translation function with keys in
  one strings table.
- Never convey state by colour alone; pair colour with shape or icon.
- Minimum touch target 44 pt; scalable text; reduced-motion option for
  shakes and flashes.
- Full keyboard and gamepad focus navigation.
