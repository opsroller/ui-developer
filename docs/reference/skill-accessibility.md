# Skill: accessibility

| Field | Value |
|---|---|
| Name | `accessibility` |
| File | `skills/accessibility/SKILL.md` |
| Trigger (description) | Use when building or reviewing any UI players must perceive or operate - text, colour, icons, HUD, subtitles, motion, timers, settings menus, screen-reader or narration support - and when planning which accessibility features a game's UI should offer. |
| Companion file | `skills/accessibility/thresholds.md`: text size, spacing, contrast, target size, flashing tables and the basic checklist. |
| Docs owed by its work | Reference listing each accessibility feature, its setting and default; explanation for the chosen feature set; how-to for auditing a screen. |

## Sections

- 1. Defaults every screen must meet
- 2. Features the UI usually owns or hosts
- 3. Screen narration and assistive tech hooks
- 4. Audit method (per screen)
- Decision rules
- Failure modes
