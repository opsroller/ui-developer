# Skill: localization

| Field | Value |
|---|---|
| Name | `localization` |
| File | `skills/localization/SKILL.md` |
| Trigger (description) | Use when adding or changing any user-visible text, number, date, currency, name or image with text; when adding a language; or when preparing UI for translation (internationalization, pseudo-localization, right-to-left, CJK, fonts). |
| Docs owed by its work | Reference for string-key conventions and supported locales (the string tables carry translator context); how-to for adding a string or language; explanation for format or library choices. |
